    Como editar este hotsite

    Todas as planilhas estão declaradas em um único array JavaScript chamado ITENS. Adicionar, remover ou editar é só manipular esse array — nada mais.

    • +

      Adicionar: copie um bloco inteiro e cole no fim do array, editando os campos.

    • ✎

      Alterar link: edite o campo link com o novo endereço do Apps Script.

    • ×

      Remover: apague o bloco correspondente.

    • ◉

      Mudar status: troque status: 'pend' por 'on' quando o link estiver ativo.

    Estrutura de cada item

    { cat: 'docente', // categoria (chave do CATS) icon: '🎓', // emoji ou ícone (único por item) titulo: 'Nome do item', // título exibido freq: 'Semestral', // periodicidade desc: 'Breve descrição.', status: 'on', // 'on' | 'soon' | 'pend' link: 'https://script.google.com/...', planilhaId: '' // (opcional) p/ automação futura }

    💡 Os itens aparecem sempre em ordem alfabética pelo título — dentro de cada categoria e também na visão "Todas".
